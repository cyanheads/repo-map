# 0.14.0 — 2026-10-20

## Added

- **`.env.example`** lists every setting the CLI reads, with its default.
- **`.github/SECURITY.md`**, **`CONTRIBUTING.md`**, and **`CODE_OF_CONDUCT.md`**, plus a CodeQL workflow (`.github/workflows/codeql.yml`) scanning Python and Actions.
- **`release-and-publish` skill** for pushing, publishing to PyPI, and cutting the GitHub release.
- **PyPI metadata**: keywords, classifiers, and Repository, Issues, and Changelog links.

## Changed

- **Default model** `anthropic/claude-sonnet-4.6` → `anthropic/claude-sonnet-5.5` (`OPENROUTER_MODEL_NAME`, `--model`).
- **Analysis prompt** rewritten. Every field and enum value now has a definition, `null` is the expected answer for a well-kept file, generic filler and hedging are ruled out, and the worked example no longer describes repo-map's own OpenRouter client. `ANALYSIS_CONTRACT_VERSION` 1 → 2, so every cached analysis is reanalyzed once.
- **Request context**: each request carries a names-only repository layout (directories only past 1,000 entries) plus one-line notes on the target's internal imports and same-directory files. Previously it carried the full tree with every file's description and the parser's import and symbol lists, so per-request context no longer grows with the number of analyzed files.
- **Request parameters**: requests no longer send `temperature`. They mark the layout for prompt caching (`cache_control`) and send a `session_id`, so OpenRouter keeps a run's requests on the provider holding the cached prefix.
- **Toolchain** moved from Poetry to uv. `pyproject.toml` uses PEP 621 metadata with the `uv_build` backend, `uv.lock` replaces `poetry.lock`, and resolution skips releases younger than three days (`[tool.uv] exclude-newer`). `src/repo_map/` gains an `__init__.py` and is now a regular package instead of an implicit namespace package. Python 3.14 is a declared classifier.
- **`make check`** replaces `scripts.py` as the gate: `ruff check`, `ruff format --check` (Ruff now formats, replacing Black), pyright (new), pytest, `uv lock --check`, and the changelog index check.
- **Project skills** live in `.claude/skills/`, with `.agents/skills` a symlink to it. The root `skills/` source, the mirror-sync script, and its hook are gone, and every skill is rewritten for the uv toolchain. `AGENTS.md` is a symlink to `CLAUDE.md`.
- **Changelog** split into per-version files under `changelog/`; `CHANGELOG.md` is now a generated index (`make changelog`).
- **Package description** is now "Map a repository as a Markdown tree with LLM-written notes on each file." The README is shorter and leads with install and usage.
- **Direct-dependency lower bounds** now match the locked versions.

## Fixed

- **Retry backoff**: a transport error on the final retry attempt no longer waits out another backoff (up to 20 seconds) before the file is reported as not analyzed.
- **Relative paths**: `repo-map .` now names the report and its tree root after the directory, not `._repo_map.md` and `/ (.)` ([#31](https://github.com/cyanheads/repo-map/issues/31)).

## Security

- **Source markers**: the target's source sits between marker lines tagged with a digest of that source, so file content can no longer forge the end of the source block. File names in the layout have control characters escaped, and related-file notes are flattened to one line.
